# Gilan TV App

Workspace for inspecting the Android application and implementing group reordering.

## Requested group reordering

- Mobile: long-press a group for about one second to enter reorder mode; highlight the selected group in red.
- Mobile: drag the group to its new position.
- Android TV: long-press the OK button to enter reorder mode, then use directional keys to move the selected group.
- Press OK to confirm and exit reorder mode.
- Save the order persistently so it remains after restarting the app.
